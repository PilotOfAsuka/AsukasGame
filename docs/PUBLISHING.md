# 📦 Публикация CardForge

Этот репозиторий содержит **готовую веб-сборку Godot** для GitHub Pages и **APK-файлы в GitHub Releases**. Исходный проект Godot поддерживается отдельно.

## Веб-версия

**Адрес:** https://pilotofasuka.github.io/AsukasGame/

Файлы экспорта размещаются **в корне ветки `main`**. Действующие связанные файлы: `index.html`, `index.js`, `index.wasm`, `index.pck`, `index.manifest.json`, `index.service.worker.js`, `index.offline.html`, изображения, иконки и audio worklet-файлы.

1. Создайте новую веб-сборку CardForge в Godot с тем же базовым именем экспорта `index`.
2. Сохраните копию текущей рабочей сборки или ориентир на предыдущий коммит.
3. Загрузите **все взаимосвязанные экспортированные файлы одной версии**, сохранив относительные пути. Не смешивайте новый `index.pck` со старым `index.wasm` / `index.js`.
4. Обновите `version.json`: номер версии и краткое описание изменений. Следите за совпадением версии с Android-релизом, если они выпускаются вместе.
5. Убедитесь, что `.nojekyll` остаётся в корне. Не удаляйте вспомогательные файлы экспортированной игры, пока не проверите, что они больше не нужны.
6. После публикации проверьте запуск страницы, загрузку Godot, интерфейс, карточные игры, работу на мобильном устройстве и подключение к сетевой комнате.

**Важно:** Service worker может кэшировать файлы и показывать предыдущую сборку. При проверке используйте обновление страницы, приватный режим или очистку данных сайта, если видите старую версию.

## Android APK / Releases

1. Экспортируйте и проверьте APK из соответствующей версии Godot.
2. Создайте GitHub Release с тегом вида `v0.15.0` и названием `CardForge 0.15.0` (номер указан **только как пример**, не как опубликованная версия).
3. Прикрепите APK с согласованным именем `CardForge-0.15.0.apk`.
4. Запишите изменения, совместимость мультиплеера и важные исправления.
5. Добавьте запись в [CHANGELOG.md](../CHANGELOG.md), проверьте ссылку `/releases/latest` и скачивание APK.

> При публикации Android-релиза не удаляйте файлы предыдущих релизов без веской причины: они полезны для истории версий и диагностики.

## Проверочный список перед выпуском

- [ ] Веб-версия открывается и загружает игру
- [ ] Основные карточные режимы запускаются
- [ ] Локальный и интернет-мультиплеер проверены (если изменялись)
- [ ] Android APK устанавливается и запускается на целевом устройстве
- [ ] Версия и описание изменений согласованы
- [ ] GitHub Pages не содержит смешанных файлов разных экспортов
- [ ] Ссылка на последний релиз и APK работает

## Важное разделение

- **Ветка `main`** — опубликованные веб-файлы и документация.
- **GitHub Releases** — версии и Android APK.
- **Исходники Godot** — не являются частью этого репозитория.

Не добавляйте в публичные файлы токены бота, секреты сервера, пароли и ключи подписи Android.
